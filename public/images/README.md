# Terrarun website image set

Original, project-specific image assets generated for the trust and motion pass.
The site serves the optimized WebP files in this directory; source PNGs remain
outside the repository in Codex's generated-image store.

- `runner-dawn.webp` — landing-page human support image (1536×1024)
- `runner-dawn-square.webp` — square crop for narrow/social placements (1024×1024)
- `trust-paddle.webp` — protected app → checkout → app handoff (1600×880)
- `how-loop.webp` — run a loop vignette (1200×1200)
- `how-claim.webp` — claim the area vignette (1200×1200)
- `how-defend.webp` — defend and steal vignette (1200×1200)
- `og.png` — Open Graph card (1200×630)

All artwork avoids fabricated badges, ratings, testimonials, payment marks and
security certifications. The payment illustration is conceptual; factual copy
beside it explains Paddle's actual role.
